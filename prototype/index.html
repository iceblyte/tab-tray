Tab Tray 界面原型Tab Tray UI Prototypes

Obsidian 桌面端插件：浏览器式标签「固定 + 分组」收纳。本套原型覆盖 PRD v1.3 的全部 UI 触点——分组侧边栏、紧凑固定行、五成员入口、删除确认、设置页、命令面板与 Notice 体系；默认暗色主题，右上角可切换亮色与中英文。纯静态 HTML/CSS/JS，无构建，直接浏览器打开。 An Obsidian desktop plugin providing browser-style tab grouping and pinning. This prototype set covers every UI touchpoint of PRD v1.3 — group sidebar, compact pinned row, five member entries, delete confirmation, settings, command palette and notices. Dark theme by default; light theme and zh/en switching top-right. Pure static HTML/CSS/JS.

依据：PRD v1.3 · 方案设计 v1.1 · 增补决议——按分组染色纳入原型范围（2026-10-06 用户确认，原 v1.1 方向提前呈现） Basis: PRD v1.3 · SD v1.1 · Addition — group coloring included per user confirmation (2026-10-06, originally a v1.1 direction)

范围与决策记录Scope & decisions

  • ✓ 原型载体Vehicle — 模拟完整 Obsidian 桌面外壳（标题栏/Ribbon/侧栏/标签栏/编辑器），F2/F4/F3-2 嵌在真实位置呈现。Full Obsidian desktop shell mock; F2/F4/F3-2 shown in their real positions.
  • ✓ 计数呈现Counts — 组行一体显示 n/m（m = 成员数），悬停 tooltip 说明「已打开 n / 共 m」。Groups show n/m inline (m = member count), tooltip spells out "n of m open".
  • ✓ 侧栏折叠Sidebar folding — 组头左侧 ▾/▸ 仅折叠侧栏显示，不影响 F2 展开/收起语义（PRD 未定义，按确认补充）。The ▾/▸ chevron only folds the sidebar display; F2 semantics untouched (added per confirmation).
  • ✓ 按分组染色Group coloring — 2026-10-06 用户确认纳入原型：组色胶囊环绕成员标签头（Chrome 式，方案 A 色点为默认，方案 B 组名 chip 供比选）+ 紧凑固定行组色角标；单文件不染色。对应 PRD §2.3 v1.1 方向。Confirmed 2026-10-06: group-color capsules around member tabs (Chrome-style; variant A default, B name chip for comparison) + pinned-row color badges; single files stay uncolored. PRD §2.3 v1.1 direction.
  • ✓ 双语与主题i18n & theme — 全部屏幕支持中英切换（F8）与明暗双主题（R8 色板各调两版）；文件名保持原文（库内容不翻译）。All screens switch zh/en (F8) and dark/light (R8, two tuned palette variants); file names stay verbatim.
  • ✓ 交互深度Interactivity — 静态高保真 + 关键弹层可点击演示（组菜单、色板、主题/语言/染色开关）；无真实逻辑、无框架、无构建。Static hi-fi with clickable popovers (group menu, palette, theme/lang/color toggles); no real logic, no framework, no build.
