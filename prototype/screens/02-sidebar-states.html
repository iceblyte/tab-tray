① 成员悬停态Member hover — 行尾出现 × 移出按钮（F3-4）；挂起/丢失成员同屏对照× remove button appears (F3-4); suspended/missing members shown alongside

② 行内重命名 + 色板Inline rename + palette — Enter 确认 / Esc 取消；10 色固定色板（R8），当前色带选中环，点击色格可预览Enter confirms / Esc cancels; fixed 10-color palette (R8) with current-color ring, click to preview

③ 拖拽排序Drag reorder — 「日常」被拖起（半透明），项目与日常之间显示强调色插入线；拖到其他组头 = 移入该组尾部（F3-5）"Daily" being dragged (dimmed); accent insertion line between groups; drop on a group header = move to its end (F3-5)

④ 空分组Empty group — 合法（R9），显示拖入引导文案Legal (R9), with a drag-in hint

⑤ 组头悬停Group head hover — 出现 展开 ▸▸ / 收起 ◂◂ / 更多 ⋯ 三个操作钮，计数暂时隐藏避免拥挤Expand / collapse / more buttons appear; the count hides to avoid crowding

拖拽落点规则：组头 = 移入该组尾部；成员行之间 = 精确插入位。文件从文件树拖入侧边栏分组走同一落点规则（F3-3）。Drop rules: on a group header = append to that group; between member rows = precise insertion. Dragging files from the file tree (F3-3) follows the same rules.
