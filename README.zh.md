# Tab Tray

为 Obsidian 桌面端提供浏览器式的标签分组：具名、可配色、一键展开与收起，外加紧凑固定行。

这个插件真正要解决的问题不是「能不能分组」，而是**重启之后分组还在不在**。每一次写入都走防抖、原子替换、备份轮换的写盘路径，所有降级分支都有单测覆盖，而不是「测过没复现」。

English documentation: [README.md](./README.md).

## 功能

- **分组侧边栏** —— 色点、名称、成员数与 `n/m` 已开计数（跨窗格、跨窗口去重）。新建、行内重命名、10 色固定色板改色、拖拽排序、删除二次确认。
- **展开与收起** —— 展开默认替换当前窗格（按住 Ctrl/Cmd 改为追加）；收起关闭该组在当前窗口内的全部标签，其他窗口（含 Popout）不受影响。
- **六个成员入口** —— 文件浏览器右键、标签头右键、从文件树拖入、成员行悬停 ×、侧栏内跨组拖拽、合并侧栏右键。六个入口终点是同一个校验过的变更 API，不会各自漂移。
- **紧凑固定行** —— 已固定的标签在标签栏起始侧收缩为图标，原生 tooltip 保留；左键、右键、中键全部保持原生行为。
- **按分组染色** —— 组员标签头以组色环绕；未入组文件不染色。
- **一个侧栏，一份列表** —— 分组与全部已打开标签合并显示：分组节保留全部持久成员，未分组与库外标签列在下方；搜索、聚焦、关闭、固定、加入/移出分组、一键收纳都在同一处。
- **命令与快捷键** —— 每个分组的展开/收起命令，以及全局命令；侧边栏关闭时同样可用。
- **双语** —— 中文与英文，默认跟随 Obsidian 语言设置。

## 环境要求

- Obsidian 桌面版 **1.14.0** 及以上。
- 仅桌面端：插件作用于标签栏与工作区布局，移动端没有对应形态。

## 安装

在进入社区插件市场之前，手动安装：

1. 从最新 Release 下载 `main.js`、`manifest.json`、`styles.css`。
2. 放入 `<你的库>/.obsidian/plugins/tab-tray/`。
3. 在「设置 → 第三方插件」中启用 **Tab Tray**。

## 使用

点击 ribbon 的分组图标，或执行命令「打开分组侧边栏」。一个列表依次显示分组、未分组标签与库外标签；命令「打开标签管理面板」打开的是同一个侧栏。新建分组后，在文件浏览器或标签头上右键即可加入文件；已在组内的标签，同一菜单里会出现「从「X」移出」。

点击组名是切换：当前窗口有组员打开时收起，否则展开。展开时按住 Ctrl/Cmd 改为追加。

被原生固定的组员会显示 📌。收起与替换都会跳过它，取消固定后自动恢复为普通成员——这里没有需要修复的状态，因为钉住状态是从标签本身读出来的，不落盘。

## 你的数据

分组保存在 `.obsidian/plugins/tab-tray/data.json`。

- 每次变更约 500ms 内以原子替换写入，写入前把上一份内容轮换进 `data.json.bak`。
- 主文件无法解析时自动回退备份并提示；无法解析的文件会被另存，绝不覆盖。
- 同步工具产生冲突副本（`data.sync-conflict-*.json`）时，加载最新可解析的一份，冲突文件本身不删除。
- 禁用或卸载插件**不会删除**你的数据。
- 插件不发起任何网络请求、不收集遥测；只读取文件路径与元数据，不读取文件内容。

钉住状态与「丢失」标记都是运行时派生的，**刻意不写入磁盘**，因此不会过期。

## 开发

```bash
npm install
npm run dev        # esbuild watch -> main.js
npm run build      # 类型检查 + 生产构建
npm test           # Vitest，覆盖核心层与决策层
npm run lint       # Biome
npm run typecheck  # tsc --noEmit
```

架构、持久化设计与决策记录见 [docs/DESIGN.md](./docs/DESIGN.md)；需求基线见 [docs/PRD.md](./docs/PRD.md)；手工验收清单见 [docs/ACCEPTANCE.md](./docs/ACCEPTANCE.md)；实现所遵循的 UI 原型在 [prototype/](./prototype/index.html)。
