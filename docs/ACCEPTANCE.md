## 1. 功能验收（A1–A10）

### A1 分组增删改查

- [ ] 1.1 点「新建分组」→ 出现新行并**直接进入行内编辑**；输入「研究」回车 → 名称保存，侧栏即时更新。
- [ ] 1.2 `⋯ → 重命名` → 改名后 Enter 保存；再改一次按 Esc → 名称回退。
- [ ] 1.3 `⋯ → 更改颜色` → 弹出色板（5×2，共 10 色，当前色带外环）→ 选绿色 → 色点变绿。
- [ ] 1.3b **按分组染色**：打开一个组员文件的标签 → 标签头出现该组颜色的胶囊描边、色点与淡色底；**未选中时也能明显看出组色**；选中后底色加深、圆角仍为组色（不会变回白色）。未入组文件保持原生样式。到设置页关闭「按分组染色」→ 所有标签**立即**恢复原生。
- [ ] 1.4 `⋯ → 删除分组…` → 弹出确认框，文案含分组名与成员数、并写明「不会删除任何文件」；点「取消」分组仍在。
- [ ] 1.5 再次删除并确认 → 分组消失，**文件树里的文件仍在**。
- [ ] 1.6 拖拽组头上下移动 → 出现插入指示线，松手后顺序变化。

### A2 六个成员入口一致 + 两条拦截

- [ ] 2.1 **入口 1**：文件树右键 `.md` → 菜单里有「添加到分组」→ **悬停**它 → 右侧展开分组列表（当前所属组带 ✓，末尾「新建分组…」）→ 选一组 → 侧栏出现该成员。
- [ ] 2.2 **入口 2**：标签头右键 → 同样的「添加到分组」→ 悬停 → 选另一组 → 成员**移动**过去并提示「已从 A 移动到 B」。
- [ ] 2.2b **入口 2（后台标签）**：先切到另一个标签，让目标标签处于**未选中**状态，再右键它 → 「添加到分组」**仍然存在**，悬停同样展开。
- [ ] 2.3 **入口 3**：从文件树把一个 `.canvas` 拖到侧栏分组上 → 加入该组（组行高亮反馈）。
- [ ] 2.4 **入口 4**：成员行悬停 → 出现 × → 点击移出。
- [ ] 2.5 **入口 5**：把成员拖到另一个组的组头 → 落到该组末尾；拖到某成员行上半/下半 → 精确插入到该位置。
- [ ] 2.6 **入口 6**：执行「打开标签管理面板」→ 打开合并侧栏 → 在「未分组」节右键任一条目 → 「添加到分组」→ 选组 → 该条目移入对应分组节。
- [ ] 2.7 **新建分组**：任一入口选「新建分组…」→ 弹出对话框，可填名称、选 10 色之一 → 点「创建分组」→ 新组出现且该文件已在组内；点「取消」→ **不创建任何分组**。侧栏顶部「新建分组」按钮走同一对话框。
- [ ] 2.8 **R5 拦截**：把某个标签固定（标签右键 → Pin），再对它执行 2.1 / 2.2 / 2.6 → 一律弹出「该标签已固定，请先取消固定再加入分组」，分组不变。
- [ ] 2.9 **R12 拦截**：打开 vault 外的 `external-test.md`，对它的标签执行 2.1 / 2.2 / 2.6 → 弹出「库外文件不支持加入分组」。
- [ ] 2.10 同一文件重复加入同一组 → 不产生重复成员。
- [ ] 2.11 **从分组移出（标签头）**：右键一个已在组内的标签 → 菜单出现「从「X」移出」→ 点击 → 标签染色消失、侧栏该成员消失、提示「已将「文件」从「X」移出」；**文件本身仍在**。
- [ ] 2.12 **从分组移出（侧栏）**：右键合并侧栏中的组员行 → 同样有「从「X」移出」；未入组/库外条目的菜单中**没有**这一项。

### A3 展开（替换 / 追加）

- [ ] 3.1 组内 5 个成员；当前窗格开 3 个**非组员**标签 → 点击组名 → 当前窗格只剩这 5 个组员，计数变为 `5/5`，并提示「已展开「X」——已替换当前窗格的 N 个标签」。
- [ ] 3.2 先固定一个无关标签，再执行 3.1 → **固定标签保留**，其余被替换。
- [ ] 3.3 按住 Ctrl/Cmd 点击组名 → 追加模式：现有标签一个不关，只补未打开的组员。
- [ ] 3.4 同一文件在另一个窗格也开着 → 计数仍为去重后的值（不重复计）。
- [ ] 3.5 首次执行替换式展开 → 额外出现一次「按住 Ctrl/Cmd 展开可改为追加模式」的提示。

### A4 收起（窗口作用域 / 多窗格 / 固定跳过）

- [ ] 4.1 让某组员在**同一窗口的两个窗格**各开一次 → 收起 → 两处都关闭。
- [ ] 4.2 让同一文件在 **Popout 窗口**也打开 → 在主窗口收起该组 → Popout 里的标签**仍在**。
- [ ] 4.3 固定一个组员 → 该成员**自动移出分组**并提示「已固定——已将「文件」从「X」移出」；分组 `n/m` 减 1，标签进入「已固定」节。
- [ ] 4.4 取消固定 → 该标签从「已固定」移到「未分组」；**不会**自动回到原分组，手动「添加到分组」后才重新成为组员。
- [ ] 4.5 收起当前窗口最后一组且窗口内已无其他标签 → 自动补一个空白标签，窗口不会变成无标签状态。

### A5 紧凑固定行

- [ ] 5.1 固定任意标签 → 该标签收缩为 **40px 图标**并排到标签栏**起始侧**，标题与关闭钮隐藏，**图标本身可见**（笔记类标签原本被 Obsidian 隐藏图标，插件已显式恢复）。
- [ ] 5.2 悬停图标 → 显示完整文件名 tooltip。
- [ ] 5.3 左键点击图标 → 激活该标签。
- [ ] 5.4 右键图标 → 弹出**原生标签菜单**，且其中含「添加到分组」；无论该标签是否处于选中状态都应有此项。
- [ ] 5.5 中键点击图标 → 保持原生行为（关闭并取消固定）。
- [ ] 5.6 连续固定 6 个以上标签 → 图标不换行、不被压缩变形；普通标签先被压缩（溢出交给 Obsidian 原生标签栏）。
- [ ] 5.7 设置 → 关闭「启用紧凑固定行」→ **立即**恢复原生标签样式；再打开 → 立即恢复图标。

### A6 命令面板

- [ ] 6.1 命令面板输入「分组」→ 能看到：`打开分组：X`、`收起分组：X`（每个分组各两条）、`新建分组`、`收起当前分组的标签`、`打开分组侧边栏`、`打开标签管理面板`、`收起全部分组`。

- [ ] 6.3 给某分组的「打开分组」绑一个快捷键 → 重命名该分组 → 快捷键**仍然有效**（命令 id 未变）。

- [ ] 6.5 执行「收起当前分组的标签」：活动标签属于某组时收起该组；不属于任何组时提示「当前活动标签不属于任何分组」。

### A7 重命名跟随与丢失标记

- [ ] 7.1 Obsidian 运行中，在文件树重命名一个组员 → 侧栏成员名**立即**跟着变。
- [ ] 7.2 Obsidian 运行中，把组员移动到另一个文件夹 → 路径跟随，重启后仍正确。
- [ ] 7.3 Obsidian 运行中删除一个组员 → 该成员显示「丢失」徽标，**不消失**。
- [ ] 7.4 关闭 Obsidian，在系统里重命名一个组员文件，再启动 → 该成员显示「丢失」，其余成员完好。
- [ ] 7.5 把文件改回原路径 → 「丢失」徽标自动消失（最迟在一次重命名事件或启动扫描后）。
- [ ] 7.6 对含丢失成员的分组执行展开 → 跳过丢失项并提示「已跳过 N 个丢失的成员」，其余成员正常打开。

- [ ] 9.1 组员在标签栏被固定 → **自动移出分组** + Notice「已固定——已将「文件」从「X」移出」；分组 `n/m` 减 1。
- [ ] 9.2 该标签出现在侧栏「已固定」节，**不再**出现在任何分组节。

### A10 合并侧栏（F1 + F9）

- [ ] 10.1 点 ribbon 图标 → 打开**一个**侧栏；顶部只有搜索框与「一键收纳」，**没有**「分组 / 标签」切换；下方依次是分组、未分组、库外。
- [ ] 10.1b 执行命令「打开标签管理面板」→ 打开同一个侧栏（不再切换模式）。
- [ ] 10.2 分节顺序为 **分组（按侧栏顺序）→ 已固定 → 未分组 → 库外**，组色圆点与分组节一致。
- [ ] 10.3 同一文件在两个窗格打开 → 列表只出现一次，并显示 `×2` 徽标（悬停提示「在 2 个窗格中打开」）；分组节、已固定节与未分组节行为一致。
- [ ] 10.4 只存在于 Popout 窗口的标签 → 显示 `Popout` 徽标。
- [ ] 10.5 点击分组节成员 → 已打开则聚焦、未打开则在当前窗格打开；点击「已固定」/「未分组」/「库外」条目 → 聚焦该标签（跨窗口时切到那个窗口）。
- [ ] 10.6 悬停 ×：分组节 = **移出分组**（文件保留）；「已固定」/「未分组」/「库外」节 = 关闭该文件在**当前窗口**内的全部标签，其他窗口不受影响。
- [ ] 10.7 右键菜单：
  - 分组节成员：固定、添加到分组、从「X」移出、关闭、关闭其他（已打开时）；
  - 已固定条目：取消固定、添加到分组（库内文件）、关闭、关闭其他；
  - 未分组条目：固定、添加到分组、关闭、关闭其他；
  - 库外条目：固定/取消固定、关闭、关闭其他（**没有**添加到分组）。
- [ ] 10.8 「关闭其他标签」→ 该文件与所有**固定**标签保留，其余关闭。
- [ ] 10.9 搜索框输入文件名片段 → 同时过滤分组成员、已固定、未分组、库外；输入分组名 → 显示该组**全部**成员；无匹配时显示「没有匹配的条目」；有匹配时分组计数仍显示完整的 `n/m`。
- [ ] 10.10 顶栏「一键收纳」→ 全部分组收起；**固定、库外、未分组**标签一律不动。
- [ ] 10.11 库外文件显示「库外」角标（含被固定的库外标签）；条目菜单中**没有**「添加到分组」；库外标签**不参与**分组染色。
- [ ] 10.12 打开/关闭标签、切换窗口 → 列表实时更新，无需手动刷新。
- [ ] 10.13 分组节与「已固定」/未分组/库外节的折叠相互独立；分组折叠只影响显示，不改变成员。

- [ ] 10.14 搜索状态下拖拽组员被禁用（避免只重排了可见子集）；清空搜索后拖拽恢复。

## 3. 已知限制（不算缺陷，验收时按此判定）

| # | 限制 | 原因 / 判定口径 |
|---|---|---|
| 1 | 「添加到分组」使用 Obsidian 原生悬停二级菜单 | 走宿主内部 `MenuItem.setSubmenu()`（与「复制路径 ›」同一套实现）。若某版本移除该方法，自动降级为「点击后弹出第二个原生菜单」，功能不丢失。 |
| 2 | 固定图标过多时不单独滚动 | 按 F4「不另建独立容器」的约束，溢出交给 Obsidian 原生标签栏：图标固定宽度不收缩，普通标签先压缩。 |
| 3 | 合并侧栏的「所在窗格」以 `×N` 徽标 + 悬停提示呈现 | 未做逐窗格展开列表；同文件多窗格仍计 1 条。 |
| 3b | 分组与标签合并为**一个列表**，不再是两个模式 | 按你的要求整合；PRD F9 原写「ribbon 第二图标 toggle 右侧面板」。功能未减：分组管理、搜索、一键收纳、聚焦/关闭/固定/加入分组都在同一列表内。 |
| 3c | 分组节显示**全部持久成员**（含未打开），未分组/库外节只显示**当前打开**的标签 | 两种数据本质不同：分组成员是持久资产，未分组/库外没有持久归属。这不是遗漏。 |
| 3d | **固定即自动移出分组** | 2026-10-27 用户决议，取代 PRD R6 的「挂起-回归」；移出时弹 Notice，取消固定不会自动回组。 |
| 4 | 侧栏里的文件（拖到左右侧边栏打开的笔记）不参与计数、不会被收起或关闭 | 侧栏 leaf 不属于标签栏模型，纳入会被误关。 |
| 5 | 侧栏分组的 ▾ 折叠是**会话内**状态 | 只影响显示，不写入 `data.json`；重开视图后恢复展开。 |
| 6 | 按分组染色属于本次确认的 v1 增项 | PRD §2.3 原列为 v1.1；设置页可关闭。 |
| 7 | 切换语言后 ribbon 图标的悬停文字不立即更新 | Obsidian 的 ribbon 标题在注册时固定；重启后更新。 |
| 8 | 「紧凑固定行降级」无法人工构造 | 需要 DOM 不兼容的真实环境；代码路径已走查，判定标准为 5.8。 |
